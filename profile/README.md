# RustUse

**Composable sets of primitive Rust utility crates.**

RustUse is an open-source collection of small, focused Rust utility crates organized into practical `use-*` sets.

The goal is to provide reusable primitives that are easy to understand, easy to compose, and useful across real Rust projects without pulling in large frameworks or overly broad dependencies.

## Sets

RustUse sets are organized as top-level repositories, with focused child crates inside each workspace.

Current and emerging sets include:

- `use-math`
- `use-color`
- `use-text`
- `use-time`
- `use-wave`
- `use-acoustics`
- `use-optics`
- `use-chemistry`
- `use-units`
- `use-measure`
- `use-rust`
- `use-id`
- `use-validate`
- `use-physics`

Each set is intended to stay narrow, documented, tested, and composable.

## Contributing

Contributors and maintainers are welcome.

Good ways to contribute include:

- improving documentation
- adding examples
- reviewing crate APIs
- filing issues for unclear behavior
- suggesting useful primitive crates
- helping maintain existing `use-*` sets

Each repository includes its own README, changelog, license files, and contribution guidance.

## Principles

RustUse favors:

- small crates
- clear APIs
- practical primitives
- Rust 2024 edition
- dual MIT or Apache-2.0 licensing
- focused workspaces
- minimal unnecessary dependencies
- composability over framework design
